# Changelog

## 2.1 - 2026-10-09

- Added Webcam Mode with four-point screen calibration and perspective correction.
- Track complete display contours while preserving manually clicked corner offsets.
- Reacquire tracking on the next captured frame after loss or a black transition.
- Preserve collected values while tracking is unavailable.
- Added a large tracking-loss warning and a higher-contrast status area.
- Show the post-calibration game-restart notice in both capture modes.
- Removed unused GUI comparison code without changing recognition thresholds.
- Updated source-build instructions and added GPL-3.0-only licensing.
